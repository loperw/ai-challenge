Пределы проверки: девять сценариев не гарантируют правильность произвольного ответа. Qwen иногда включает лишние выдержки из документации; DeepSeek отвечает точнее по объёму. Семантическая близость не гарантирует достаточность источника: отсутствие ответа обрабатывается инструкцией модели, без универсального порога сходства. Проверка фактов ответа не является автоматическим валидатором для всех пользовательских запросов. Для любого `/help`, включая облачную модель, требуется работающая локальная Ollama с моделью эмбеддингов.
