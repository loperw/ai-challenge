Во втором сценарии старый лимит в два предложения заменён четырьмя, определение группы изменилось с coroutineScope на supervisorScope, запрет примеров заменён разрешением короткого примера.

**Проверка памяти пройдена; требование стабильных ответов с источниками полностью не подтверждено.**

Обнаруженные ограничения существующего RAG:

- В четырёх ответах о корутинах (ходы 5, 7, 9, 12) модель поставила номера ссылок в тексте, но оставила `sources` и `quotes` пустыми. Такие ответы нельзя считать полноценно оформленными ответами с источниками.
- В четырёх ответах (data class: 5, 7; корутины: 2, 6) хотя бы одна цитата не совпала дословно с указанным фрагментом даже после нормализации пробелов. Причины включают пересказ, сокращение через многоточие и изменения символов OCR.
- На ходу 5 второго сценария сохранён лимит в два предложения, но ответ содержит три. Память доставляет условие модели, но сама по себе не гарантирует его соблюдение.
- Поиск иногда возвращает тематически близкие, но недостаточные фрагменты. Итоговая памятка data class неполная; одна из цитат касается делегирования и не подтверждает основную тему. Наличие номера и буквального совпадения цитаты не доказывает смысловую поддержку ответа.

Рекомендуемые следующие изменения: проверять номера источников и обязательность метаданных перед показом ответа; проверять цитаты и соответствие утверждений источникам; при нарушении делать ограниченную попытку исправления, затем честно сообщать о нехватке подтверждения. Отдельно улучшить подбор фрагментов для уточняющих вопросов и контроль формальных ограничений ответа. В этой ветке поведение проверки цитат предыдущей версии не менялось.
