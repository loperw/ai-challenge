# Развертывание — 13 октября 2026

Ветка: `codex/ai-challenge-30`, от `codex/ai-challenge-29`.

Развернут существующий проект чат-агента на Ubuntu 24.04, VPS 1 CPU / 1967 MiB RAM.
Доступ к чату — через частное соединение; адрес хранится вне репозитория.
Открытие на телефоне подтверждено пользователем; веб-интерфейс дополнительно
проверен через временный SSH-туннель. Пароля в чате нет, доступ ограничен VPN.

## Проверки на реальной модели

Qwen3 0.6B Q4_K_M, Ollama 0.40.3. Два runner slots, контекст 4096 на слот,
KV cache q8_0, flash attention, batch=64, prompt RAM cache выключен.

| Пара | Время полного запроса, секунд | Ответы перекрываются |
| --- | --- | --- |
| 1 | 77.9 / 78.4 | Да |
| 2 | 94.6 / 95.5 | Да |
| 3 | 84.8 / 80.7 | Да |

Запрос включает обновление памяти агента и генерацию до 160 токенов ответа.
В каждой паре оба потока начали возвращать текст до завершения первого.
Два активных слота также подтверждены журналом runner (`-np 2`).
Это ограниченный тест, не гарантия круглосуточной работы под любой нагрузкой.
На одном CPU скорость невысока; модель существенно слабее 2B.

После применения финального admission gate проверены две активные генерации,
отказ третьей с HTTP 429 и успешный запрос после их окончания.

## Лимиты и доступ

- Контекст выше 4096 и ответ выше 256: HTTP 400.
- Чрезмерно длинное сообщение и HTTP body >64 KiB: HTTP 413.
- 13-я изменяющая операция в минуту с одного IP: HTTP 429, Retry-After: 60.
- Облачный провайдер/посторонняя модель: HTTP 400.
- Запрос с посторонним Origin: HTTP 403.
- Внешний компьютер не смог подключиться к публичным портам 3000 и 11434.
- HTTP API доступен через частное соединение.
- Все AI-службы имеют системные ограничения внешних соединений; локальные ключи
  облачных провайдеров и история ноутбука на VPS не переносились.

Автозапуск chat-agent, chat-agent-network, ollama включен. Перезапуск приложения
проверен последующей генерацией. Перезагрузка всего VPS не выполнялась, чтобы
не прерывать существующий VPN.

После теста: доступно около 519 MiB RAM; swap занят примерно на 68 MiB.
Событий OOM за период теста в журнале ядра не найдено. Ранние настройки без
оптимизации кэша использовали почти всю память, поэтому были заменены.

125 локальных тестов проекта прошли. Машиночитаемые отчеты лежат в `evidence/`.
История на VPS содержит тестовые диалоги. Все устройства владельца используют
общую историю; отдельные conversationId сохраняют независимые сообщения.
