# AI Chat — интерфейс для DeepSeek

Небольшое локальное веб-приложение для общения с моделями DeepSeek через API. Оно состоит из чата и правой панели настроек, где можно выбрать используемую модель и температуру ответа.

## Возможности

- Отправка сообщений в DeepSeek Chat Completions API.
- Потоковая выдача: текст ответа появляется по мере генерации.
- Поддерживаемые модели: `deepseek-v4-flash`, `deepseek-v4-pro`, `deepseek-v4-flash-vision-exp`.
- Сохранение контекста текущего диалога до обновления страницы.
- Настройка температуры: от более точных до более творческих ответов.
- API-ключ не отображается в браузере и не передаётся клиентскому коду.

## Запуск локально

1. Создайте файл `.env` рядом с `server.js`, скопировав содержимое `.env.example`.
2. Укажите в нём ваш ключ:

   ```env
   DEEPSEEK_API_KEY=ваш_ключ_DeepSeek
   ```

3. Запустите сервер:

   ```bash
   node server.js
   ```

4. Откройте [http://localhost:3000](http://localhost:3000).

## Безопасность ключа

Файл `.env` включён в `.gitignore`, поэтому не будет добавлен в Git и опубликован на GitHub. В репозитории остаётся только `.env.example` без настоящего ключа.

При публикации приложения на сервере добавьте переменную окружения `DEEPSEEK_API_KEY` в настройках хостинга, а не в исходный код.
