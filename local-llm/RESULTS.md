## Запрос 2

Товар стоит 2400 рублей. Сначала скидка 15%, затем доставка 300 рублей. Сколько всего к оплате? Покажи краткий расчёт.

Ответ модели:

**Товар стоит:** 2400 рублей
**Скидка:** 15%
**Доставка:** 300 рублей

---

### Шаг 1: Применяем скидку
Скидка на 15% от 2400 рублей:

$$
2400 \times 0.15 = 360
$$

**Скидка: 360 рублей**

---

### Шаг 2: Определяем стоимость после скидки
$$
2400 - 360 = 2040 \text{ рублей}
$$

---

### Шаг 3: Добавляем доставку
$$
2040 + 300 = 2340 \text{ рублей}
$$

---

### Ответ:
**Всего нужно оплатить:**
$$
\boxed{2340} \text{ рублей}
$$

## Запрос 3

Напиши функцию Python merge_intervals(intervals), которая объединяет пересекающиеся интервалы и возвращает результат по возрастанию. Касающиеся интервалы тоже объединяются. Обработай пустой список, не меняй исходный список. Верни только код функции в блоке python, без примеров и пояснений.

Ответ модели:

```python
def merge_intervals(intervals):
    if not intervals:
        return intervals
    intervals.sort()
    merged = []
    i = 0
    while i < len(intervals):
        start, end = intervals[i]
        j = i + 1
        while j < len(intervals) and intervals[j][0] <= end:
            end = max(end, intervals[j][1])
            j += 1
        merged.append((start, end))
        i = j
    return merged
```

В третьем ответе есть ошибка: `intervals.sort()` изменяет исходный список, хотя запрос запрещает это.
