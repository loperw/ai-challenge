# Локальная Qwen в чате — ветка 27

Подключение к существующему RAG и сравнение моделей в ветке 28: [RAG.md](RAG.md).

Модель: `qwen3.5:2b-q4_K_M`. Запросы отправляются сервером приложения
только на `http://127.0.0.1:11434/api/chat`. Облачные API-ключи не нужны.

Из корня проекта в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/start-index-ollama.ps1
& ./data/tools/ollama/ollama.exe pull qwen3.5:2b-q4_K_M
npm start
```

Скачивание нужно только один раз. Если Ollama установлена через обычный
установщик, используйте `ollama pull qwen3.5:2b-q4_K_M`.

Откройте http://localhost:3000, создайте чат и в настройках выберите
**Локальная — Qwen3.5 2B (Q4_K_M)**. Во вкладке «Индексы» выберите
«Без RAG» для обычного диалога без поиска по книге.

История, потоковый вывод, JSON-формат, память и проверки инвариантов
используют выбранную локальную модель. Автоматического переключения на
облако нет. Внешние MCP-инструменты в локальном режиме отключены.
RAG при его включении требует заранее созданного индекса и установленной
локальной модели эмбеддингов; переформулировка запроса также идёт через Qwen.

Для умеренного расхода памяти Ollama получает окно 8192 токена и до 2048
токенов ответа по умолчанию; установленный пользователем бюджет ответа
передаётся отдельно. Для длинных диалогов используйте Sliding Window.
Размышления отключены (`think: false`). Первый ответ после загрузки модели
может идти дольше; тайм-аут запроса — 5 минут.

Если Ollama выключена, чат предлагает запустить скрипт. Если модель
отсутствует, показывает команду скачивания. При обрыве ответа сервер
откатывает незавершённый ход, чтобы его можно было повторить.

Проверки:

```powershell
node --test test/*.test.js
node scripts/verify-local-chat.cjs
```

Второй скрипт использует реальную Ollama, временную базу чата и сетевой
ограничитель: все fetch-запросы кроме localhost запрещены, облачные ключи
удалены из окружения тестового сервера. Проверяет HTTP-чат, поток и память диалога.

Проверено 12 октября 2026: 118 автоматических тестов прошли. Реальный HTTP-чат
сохранил слово «сапфир» и воспроизвёл его следующим ответом: первый ход
11,728 с, второй 0,939 с. Это время всего хода, включая обновление памяти.
В браузере модель ответила на арифметический вопрос, но первоначально
ошиблась (17 + 25 → 32). Работоспособность интеграции не гарантирует
фактическую точность маленькой модели.
