# Результаты локального RAG

12 октября 2026. Ветка `codex/ai-challenge-28` создана от `codex/ai-challenge-27`.
Локальная Qwen3.5 2B Q4_K_M и облачная DeepSeek Flash, температура 0.
Существующий structure-индекс книги «Программирование на Kotlin для Android».
Четыре вопроса, два независимых запуска каждого, одинаковый контекст для обеих моделей.
Rewrite и retrieval локальные; облачная передача выполнена с согласия пользователя.

| Критерий | Локальная Qwen | DeepSeek |
|---|---|---|
| Качество | Ниже: ответ о data class короче, нет copy; цитата о POJO не подтверждает перечисленные автоматически создаваемые методы | Выше на содержательном примере: перечислены equals, hashCode, toString и copy, подобраны соответствующие цитаты |
| Генерация, среднее | 1,02 с | 1,63 с |
| Генерация, медиана | 0,85 с | 1,52 с |
| Генерация, диапазон | 0,25–2,65 с | 1,34–2,14 с |
| Техническая стабильность | 8/8 без ошибок, одинаковые ответы в повторах | 8/8 без ошибок, одинаковые статусы, небольшое изменение полноты ответа |

Обе модели дали содержательный ответ на один из трёх вопросов, для которых
ожидался ответ по книге. На nullable и suspend обе вернули «Не знаю»:
retrieval не доставил достаточный контекст. На вопрос о неизвестном частном
проекте обе корректно отказались придумывать имя класса и поля.
Это оценка всего текущего RAG на малой выборке, а не общий рейтинг моделей.
Большинство ответов — короткие отказы, поэтому средняя скорость не отражает
скорость длинных содержательных ответов. На data class Qwen заняла 2,65/1,71 с,
DeepSeek — 2,14/1,83 с: заметного преимущества локальной модели здесь нет.

Общий локальный поиск с rewrite занял 9,82–10,15 с на вопрос и измерялся один
раз до генерации. Он является основной задержкой в этих замерах.
HTTP-проверка настоящего чата с памятью, rewrite и RAG на вопросе о модификаторах
видимости прошла за 13,749 с, сохранила источники и цитаты. Облачные ключи в
проверке удалены, внешние fetch запрещены. Локальный ответ не добавил номера
источников внутрь текста, но метаданные источников и цитат доступны интерфейсу.

120 автоматических тестов прошли. Дополнительные проверки покрывают локальный
RAG, переключение обратно в plain и отказ без генерации при пустом контексте.

Артефакты:

- `rag-benchmark.json`: сравнение с локальным rewrite, полный контекст и ответы.
- `rag-baseline.json`: первоначальный локальный прогон без rewrite; 8/8 отказов.
- `rag-http.json`: результат проверки HTTP-маршрута локального RAG.

Вывод: локальный режим работоспособен и стабилен на проверенной выборке.
Для качества требуется улучшать retrieval и дисциплину ссылок небольшой модели.
Облачная модель лучше использовала удачно найденный контекст, но не устранила
проблемы поиска.
