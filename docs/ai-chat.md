# AI Chat — интерфейс для DeepSeek

Предыдущий проект в этом репозитории — локальное веб-приложение для общения с моделями DeepSeek через API. Оно состоит из чата и правой панели настроек, где можно выбрать модель и температуру ответа.

Текущий проект поиска билетов описан в [главном README](../README.md) и [документации RailScout](../ticket-agent/README.md).

## Возможности

- Отправка сообщений в DeepSeek Chat Completions API.
- Потоковая выдача: текст ответа появляется по мере генерации.
- Модели в настройках чата: `deepseek-v4-flash`, `deepseek-v4-pro`, `deepseek-v4-flash-vision-exp`.
- Сохранение контекста текущего диалога до обновления страницы.
- Настройка температуры: от более точных до более творческих ответов.
- API-ключ не отображается в браузере и не передаётся клиентскому коду.

## Запуск локально

1. Создайте корневой `.env` рядом с [`server.js`](../server.js) по образцу [`.env.example`](../.env.example), если файла ещё нет.
2. Укажите ключ:

   ```env
   DEEPSEEK_API_KEY=ваш_ключ_DeepSeek
   ```

3. Запустите сервер из корня репозитория:

   ```powershell
   node server.js
   ```

4. Откройте [AI Chat](http://localhost:3000).

Команда `npm start` из корня репозитория также запускает этот чат. Для RailScout используется отдельная команда `npm run start:ticket-agent`.

## Хранение ключа

Файл `.env` исключён из Git. В репозитории хранится только `.env.example` без настоящего ключа. При размещении приложения на сервере задавайте `DEEPSEEK_API_KEY` через окружение хостинга.
