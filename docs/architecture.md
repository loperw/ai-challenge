# Структура проекта

Проект AI Chat — веб-чат с агентом и несколькими провайдерами LLM. Браузер отправляет запросы серверу Node.js. Сервер вызывает выбранную модель и возвращает ответ через SSE.

## Основные файлы и каталоги

- `server.js`: HTTP API, загрузка настроек, обработчик `/api/chat`, запуск агента.
- `agent.js`: класс Agent, сообщения, контекст, запросы к провайдерам, вызовы инструментов и сохранение ответа.
- `public/`: интерфейс; `app.js` управляет чатом, `index.html` содержит разметку, `styles.css` — оформление.
- `mcp/`: MCP-клиент, серверы и маршрутизация инструментов.
- `indexing/`: Python-пайплайн индексации PDF; `document-search.js` выполняет поиск по книге.
- `project-help.js`: отдельный поиск по README и docs для команды `/help`.
- `project-embeddings.js`: эмбеддинги Ollama, сохранение векторного индекса и поиск по косинусному сходству.
- `docs/`: документация архитектуры, API и данных проекта.
- `test/`: автоматические тесты Node.js; `scripts/`: команды индексации, проверки и оценки.

## Память и сохранение истории

`sqlite-store.js` реализует SQLiteStore и хранит диалоги, настройки, сообщения и память. `memory-store.js` экспортирует MemoryStore, наследующий SQLiteStore. По умолчанию сервер использует `data/agent-memory.sqlite`; переменная `AGENT_DB_PATH` задаёт другой путь. `agent.js` управляет контекстом отдельного диалога. `task-memory.js` извлекает память задачи. Команды `/working` и `/long` добавляют рабочую и долговременную память.

## MCP и инструменты

`mcp/client.mjs` открывает stdio-соединение и вызывает `tools/list` и `tools/call`. `mcp/registry.mjs` объединяет серверы из `mcp/servers.json`. Обычный чат использует инструменты карт, погоды, документов и расписаний. Для `/help` сервер отдельно подключает `mcp/project-server.mjs` и вызывает `git_context`: текущая ветка, commit, отслеживаемые файлы. Ветка читается из Git при каждом запросе, а не из документации. В detached HEAD ветка равна null.

## Модели

Агент поддерживает облачные провайдеры и локальную модель через Ollama. `local-provider.js` реализует локальный провайдер. `/help` передаёт документацию выбранной пользователем модели; MCP-контекст сервер получает до генерации, поэтому модели не нужна поддержка function calling.
