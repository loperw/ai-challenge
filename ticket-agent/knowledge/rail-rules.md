# Справка по поиску железнодорожных билетов

## Типы мест

- Плацкарт — открытый вагон с местами в общем пространстве.
- Купе — отдельные купейные секции.
- Сидячий — место для сидения без спального места.
- СВ — спальный вагон повышенного класса с меньшим числом мест в купе.

Названия и наличие конкретных категорий зависят от поезда и направления. Источник билетов определяет фактическую доступность.

## Условия поиска

- Разрешённые типы мест — список категорий, среди которых пользователь согласен ехать.
- Исключённые времена — интервалы отправления, которые нужно отфильтровать.
- Временной диапазон — допустимое местное время отправления.
- Свободное место считается найденным только по ответу источника билетов; языковая модель не устанавливает наличие самостоятельно.

## Уведомления

Telegram-уведомление отправляется только при совпадении маршрута, временного диапазона, исключений и выбранных типов мест. Ссылка на покупку должна вести к официальной странице, если источник её возвращает.

## Ограничения источника

Официальный сайт продажи билетов БЖД — https://pass.rw.by/. Для автоматизированного поиска нужен доступный и разрешённый интерфейс получения расписания и наличия. Не следует считать страницу сайта JSON API. Если источник недоступен или ответ нельзя разобрать, приложение показывает ошибку подключения и не сообщает о найденных билетах.
